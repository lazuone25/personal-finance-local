# Privacy Policy

**Application:** personal-finance-local  
**Last updated:** 2026-05-19

## Overview

This is a personal, non-commercial application used solely by its owner to view their own bank account information.

## Data Collection

This application does not collect, store, or share any personal data with third parties. All bank account data retrieved through the Enable Banking API is:

- Accessed only by the application owner
- Used only for personal financial tracking purposes
- Not stored on any external server

## Data Storage

Any data processed by this application is stored locally on the owner's personal device and is not transmitted to any third party.

## Third-Party Services

This application uses the [Enable Banking API](https://enablebanking.com) to access bank account information. Please refer to Enable Banking's privacy policy for details on how they handle data.
